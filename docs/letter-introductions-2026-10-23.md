# Letter introductions and clearer copy

Learner feedback requested a pronunciation explanation before each new letter, with romanization and Listen, and less repetition of small-step slogans. This AI-assisted change adds a short letter introduction before the first practice question for each of the 40 Hangul letters. The existing lesson briefing remains. A per-lesson seen-letter key prevents repeat introductions on subsequent questions or retries, and quizzes do not display these introductions.

Vowels show a sample with silent initial ㅇ so the recording isolates the vowel (ㅓ → 어, eo). Consonants distinguish the letter name from an approximate sound cue and use the existing sample syllable. Both voices use already packaged recordings and the selected pace; no model, provider, billing or account changes are involved. The introduction includes the existing NIKL reference disclosure.

Romanization source verified: National Institute of Korean Language, https://www.korean.go.kr/front_eng/roman/roman_01.do. English sound cues are approximate teaching aids, not exact equivalents. Existing letter sound cues are reused rather than generated by AI at runtime.

Landing, dashboard, review, practice, tutor, guide and feedback copy now uses more descriptive headings and fewer repeated little/small-step slogans. Korean learning examples and their translations were preserved.
