# Lesson pacing and concept introductions

Practice question ordering now groups equivalent Hangul block representations (for example ㄱ + ㅏ and 가) and spaces repeated concepts. It keeps all question IDs, answers, tips, choices, and scoring rules. A frequency-aware order avoids triples when another concept can be used, allowing a pair when needed to prevent a long repeated tail. A single-concept lesson necessarily repeats that concept. Quiz selection and scoring are unchanged.

All lessons open with an introduction. Existing authored briefings remain intact; lessons without one use their existing title, detail, first learning item, and authored tip. Hangul lessons show one additional introduction on their first block-building exercise, with a referenced reading example. That introduction appears once during practice, never interrupts the quiz, and does not increment question progress or award credit.

Validation: production web build and all 71 app tests passed. Added checks for uneven concept distributions, retained exercise IDs, equivalent block recognition, introductory content for every lesson, and the reading-to-building transition. Browser checked the existing vowel briefing and Start practice button leading into the first exercise.
