# Sori Learning Content and Motion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> Read the shared spec and this plan before changes. Complete each checkbox in order; stop at any stated external approval gate.

**Goal:** Make lesson and speaking practice more complete and engaging while growing the searchable Korean-English word bank toward 10,000 reviewed, attributable entries.

**Architecture:** Keep authored lessons in the existing TypeScript curriculum and keep the scalable dictionary in Postgres. Introduce source-aware, idempotent import validation; never let unreviewed dictionary rows become lesson or review content. Add the practiced animation using the existing CSS and reduced-motion support.

**Tech Stack:** Next.js, React, TypeScript, NestJS, Neon/Postgres, existing CSS.

**Spec:** `docs/superpowers/specs/2026-10-09-korean-speaking-ai-learning-design.md`

## Global Constraints

- Sori remains free to learners; usage caps protect the project from unbounded provider charges.
- Grow the searchable dictionary toward 10,000 distinct entries in reviewed batches.
- Each imported entry must have a stable source-aware ID, Korean headword, gloss, category or part of speech, source and license metadata, and review status.
- Keep required attribution and share-alike obligations with CC BY-SA data.
- Do not promote unreviewed entries to curriculum, generated quizzes, or spaced-repetition queues.
- Respect `prefers-reduced-motion` with immediate state changes and no decorative movement.
- Automated tests are outside this approved work; verify changes with builds and manual browser acceptance.

## Review Focus

- Duplicate spellings/senses across sources: preserve shipped IDs and keep distinct senses traceable.
- Missing Hangul syllable examples: ensure curriculum examples resolve even when they are not dictionary words.
- Weak translations or distractors: require a reviewed gloss and context before lesson inclusion.
- Unknown or incompatible licenses: block import rather than silently dropping attribution.
- Reduced-motion users or rapid repeated clicks: preserve visible completion state without repeated completion.
